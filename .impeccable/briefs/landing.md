# Public landing surface brief

## Mode and decision

- Mode: Persuade
- Direction: Braided Light
- Seed: `8feeff99`
- Approved composition: Source Loom, generated from the prompt recorded in `.impeccable/mocks/source-loom.json` (the rendered comps are not kept in the repository)
- Approval: Source Loom was the implementation plan's default, with the choice explicitly delegated when a separate approval round was unavailable.

Source Loom carries forward an asymmetric promise-and-proof first viewport. Copy and conversion sit on the left; a real, static guided answer occupies the right. The four strands explain the response mechanism and continue through later sections as connective structure. The image comp is a north star, not a literal screenshot: all copy remains semantic HTML, all source relationships use authored SVG/CSS, and mobile reorders the answer into a readable linear sequence.

## Component grammar

- Structural corners: 14px; square-edged editorial dividers may remain unrounded.
- Lines: one-pixel mineral rules; two-pixel indigo only for active or connective states.
- Elevation: no generic card shadows; use subtle inset line, rare soft material shadow on image-native sheets only.
- Type ramp: 13px metadata, 15-17px supporting copy, 22-30px section heads, 56-72px desktop display, 42-52px mobile display.
- Controls: rectangular 44px minimum actions; pills only for semantic status and theme mode.
- State: indigo for action and current position; red and green only for genuine error and success.

## Responsive commitments

At 390px, the proof follows the promise, source references become a horizontal snap-free list, the loom remains inside the content width, and no element creates page-level horizontal overflow. The answer remains a reading surface rather than collapsing into chat bubbles. Touch targets remain at least 44px and copy survives 200 percent zoom.
